# Project Overview

## Title
Fraud Operations SLA Tracking & Case Analysis

## Objective
Build a reporting solution that tracks fraud cases, SLA compliance, workload balance, and escalation patterns in a clear, leadership-friendly format.

## Scope
This portfolio covers:
- case intake and closure tracking
- SLA target monitoring
- breach analysis
- fraud risk segmentation
- agent workload reporting
- operational trend analysis

## Success criteria
A good solution should:
- replace manual weekly reporting
- show live/refreshable KPI trends
- identify SLA breaches quickly
- surface repeat issue categories
- support fair workload review by agent and queue

## End users
- fraud operations managers
- team leads
- compliance analysts
- business analysts
- technical analysts

## Design approach
The model is intentionally simple and practical:
- a fact table for fraud cases
- dimension tables for agent, queue, status, date, channel, and risk band
- SQL views for reusable reporting logic
- Power BI measures for business-facing KPIs

## Portfolio angle
This is written to fit a Technical Analyst / Business Analyst resume and shows:
- SQL reporting
- Power BI dashboarding
- stakeholder-style KPI design
- operational analysis
- fraud and SLA monitoring
