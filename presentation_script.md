# 60-Second Portfolio Walkthrough

I built this project to show how SQL and Power BI can simplify fraud operations reporting.

The problem was simple: leadership needed to know which cases were at risk of breaching SLA, where escalation volume was rising, and how much time teams were spending on manual reporting. I modeled the data in SQL, created reusable views for case and SLA analysis, and defined Power BI measures so the report could refresh cleanly and stay consistent.

The dashboard is organized into four pages: an executive overview, SLA monitoring, fraud risk analysis, and agent performance. The result is a cleaner reporting process, faster visibility into breaches, and a dashboard that is easy to explain in interviews.
