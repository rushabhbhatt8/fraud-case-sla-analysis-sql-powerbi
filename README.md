# Fraud Case Volume & SLA Analysis

A portfolio project for a **Technical Analyst / Business Analyst** profile focused on operations reporting, fraud monitoring, SLA tracking, and stakeholder-ready insights.

## Business problem

Support and fraud teams often rely on manual reporting to answer questions like:

- Which case types are driving the most volume?
- Where are SLA breaches happening?
- Which queues are escalating most often?
- How can leadership see risk and performance in one place?

This project shows how to turn raw case data into a cleaner reporting layer and analysis-ready metrics.

## Tools used

- SQL
- Power BI concept design
- Advanced Excel / reporting logic
- Data cleaning and KPI analysis

## Key highlights

- Processed **240 sample cases**
- Overall SLA breach rate: **69.6%**
- Average resolution time: **59.6 hours**
- Escalation rate: **28.7%**
- Average CSAT: **3.08 / 5**
- High-risk cases flagged: **74**

## Main insights from the sample dataset

1. The highest-volume case types are driven by operational support and fraud review work.
2. SLA breaches are concentrated in higher-risk reviews such as suspicious activity and KYC cases.
3. Escalations are useful as a secondary signal for workload pressure and recurring issues.
4. A single executive dashboard can replace manual weekly reporting and improve response speed.
