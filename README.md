# Process Flow

```text
Raw case records
      ↓
Data cleaning / standardization
      ↓
SQL analysis layer
      ↓
KPI definitions
      ↓
Power BI dashboard
      ↓
Leadership review and action
```

## Example KPI definitions

- **SLA breach rate** = breached cases / total cases
- **Escalation rate** = escalated cases / total cases
- **Average resolution time** = total resolution hours / total cases
- **High-risk cases** = records with risk score >= 75
