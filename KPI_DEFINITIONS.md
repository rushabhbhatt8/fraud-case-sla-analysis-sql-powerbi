# KPI Definitions

## SLA compliance rate
**Formula:** Closed within SLA / Total closed cases

## Breach rate
**Formula:** SLA breaches / Total closed cases

## Average resolution time
**Formula:** Average of resolution_minutes

## Escalation rate
**Formula:** Escalated cases / Total cases

## High-risk case rate
**Formula:** High-risk and critical cases / Total cases

## Backlog age
**Formula:** Current date - created date for open cases

## Reopen rate
**Formula:** Reopened cases / Total cases

## Agent productivity
**Formula:** Cases closed per agent over selected time period
